## 🧑‍🏫 About the Project

Everything from my **technical training workshops** in one repository — presentation decks, demo code, practice programs and mini-projects across **Frontend Development, Cloud Computing, Blockchain, Cybersecurity, Generative AI and Prompt Engineering**.

## ✨ Key Features

- 🌐 **Frontend** — 30-day frontend plan, HTML/CSS/JS basics (10 & 20 programs each), web dev demo decks
- ☁️ **Cloud Workshop** — fundamentals, complete guide, S3 storage demos, encryption videos
- ⛓️ **Blockchain** — Day 1 & Day 2 workshops, e-voting, supply-chain tracking, encryption demos
- 🛡️ **Cybersecurity** — complete guide deck
- 🤖 **GenAI** & 🪄 **Prompt Engineering** workshops

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | HTML5 · CSS3 · JavaScript |
| Cloud | AWS (S3) · Node.js |
| Blockchain | Python / JS blockchain demos |
| Material | PPTX · PDF · TXT programs · videos |
